# Julia Metal and Python MPS on video-sized tensors

We tested two synthetic `Float32` tensors representing **640 × 480 pixels at
30 frames per second for 10 seconds**: one channel with shape `640 × 480 × 300`,
and RGB with shape `640 × 480 × 3 × 300`. The data are deterministic random
values. Each timed call applies the universal-chisel derivation map to the
**whole tensor**. This is a tensor operation, not video decoding, encoding, or
a frame-by-frame filter.

The one-channel input has 92,160,000 elements (0.34 GiB); RGB has 276,480,000
elements (1.03 GiB). The operator coordinate vectors have 730,000 and 730,009
elements respectively. Julia Metal and Python PyTorch MPS read identical binary
inputs for each case. Both return the full result to the host inside the timed
call. Map construction and the initial tensor upload are excluded. Each process
performs five warmup calls followed by 11 timed calls; the median is reported
in **seconds**. GPU synchronization is included.

As in the larger cubic sweep, CPU timing is omitted. Julia was configured with
eight host threads; PyTorch reported twelve. Neither setting measures GPU
device workers. The run used an Apple M4 Max with 64 GiB unified memory,
macOS 27.2.1, Julia 1.12.3 with Metal.jl 1.11.1 in a temporary environment,
and Python with PyTorch 2.15.0.

## Results

![Two panels compare forward-map seconds for one-channel and RGB 640 × 480, 300-frame tensors. The one-channel medians are 0.0552 seconds for Julia Metal and 0.0571 seconds for Python MPS, with overlapping middle-half ranges. The RGB medians are 0.2520 seconds for Julia and 0.2176 seconds for Python. The panels use separate zoomed time axes; every call is in the linked CSV.](video-2026-11-18.png)

| Tensor | Julia Metal median | Python MPS median | Julia middle half | Python middle half |
| --- | ---: | ---: | ---: | ---: |
| One channel · `640 × 480 × 300` | 0.0552 s | 0.0571 s | 0.0544–0.0637 s | 0.0540–0.0616 s |
| RGB · `640 × 480 × 3 × 300` | 0.2520 s | 0.2176 s | 0.2467–0.2554 s | 0.2161–0.2208 s |

For one channel, the medians differ by 0.0019 seconds and the middle-half
ranges overlap. This run does not establish a meaningful speed advantage for
either implementation. On RGB, Python MPS measured about **1.16× faster** than
Julia Metal for this host-facing forward call. A 10-second RGB tensor therefore
took about 0.22–0.25 seconds per map application, roughly 40–46 times shorter
than the clip's duration. That comparison is not a playback or codec benchmark.

The graph zooms both time axes to show the typical calls. One Julia
one-channel call took 0.255 seconds; two Julia RGB calls took 0.369 and 0.659
seconds. [All 44 timed calls](video-results-2026-11-18.csv), including these
outliers, are retained. The median limits their influence.

The two GPU implementations agreed on 16 sampled output elements to a relative
norm difference below `1.4e-8` in each case. Their reported full-output norms
differed by `1.7e-5` relative for one channel and `1.0e-4` for RGB. Sampling
and norms do not prove full elementwise parity.

## Reproduce

Run from the repository root on a Mac with GPU access, the project-local Python
environment, and a Julia environment containing this checkout and Metal.jl
1.11.1. The commands print warmup and call progress to per-case logs. The
plotting Python environment needs NumPy and Matplotlib.

```sh
python/.venv/bin/python bench/python_vs_julia/video_inputs.py /tmp/opendleto-video-mono --shape 640 480 300
JULIA_NUM_THREADS=8 julia --compiled-modules=existing --project=/tmp/dleto-metal-bench bench/python_vs_julia/video_julia.jl /tmp/opendleto-video-mono metal 640 480 300 5 11 | tee /tmp/opendleto-video-mono/julia-metal-5x11.log
python/.venv/bin/python -u bench/python_vs_julia/video_python.py /tmp/opendleto-video-mono --shape 640 480 300 --backend mps --warmups 5 --repeats 11 | tee /tmp/opendleto-video-mono/python-mps-5x11.log

python/.venv/bin/python bench/python_vs_julia/video_inputs.py /tmp/opendleto-video-rgb --shape 640 480 3 300
JULIA_NUM_THREADS=8 julia --compiled-modules=existing --project=/tmp/dleto-metal-bench bench/python_vs_julia/video_julia.jl /tmp/opendleto-video-rgb metal 640 480 3 300 5 11 | tee /tmp/opendleto-video-rgb/julia-metal-5x11.log
python/.venv/bin/python -u bench/python_vs_julia/video_python.py /tmp/opendleto-video-rgb --shape 640 480 3 300 --backend mps --warmups 5 --repeats 11 | tee /tmp/opendleto-video-rgb/python-mps-5x11.log

MPLCONFIGDIR=/tmp/opendleto-mpl python3 bench/python_vs_julia/plot_video.py /tmp/opendleto-video-mono /tmp/opendleto-video-rgb
```

The [cubic Apple comparison](APPLE-ACCELERATE-2026-11-18.md) provides context
through `512³`.
